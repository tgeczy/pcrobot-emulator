This folder contains DOSBox-X (dosbox-x.exe), version 2026.07.02,
bundled unmodified so that the PC-ROBOT NVDA add-on works out of the box.

version 2 (see COPYING.txt in this folder). Its source code is available
at: https://github.com/joncampbell123/dosbox-x
Project homepage: https://dosbox-x.com/

If a system-wide DOSBox-X installation is present, the add-on will still
prefer this bundled copy; delete this folder to use the system one.
